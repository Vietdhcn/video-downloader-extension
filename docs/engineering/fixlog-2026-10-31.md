# Nhật ký sửa lỗi – kiểm tra toàn diện 31/10/2026

Bản gốc: `e9fea11`. Kiểm trên Chromium thật (Playwright) có nạp tiện ích từ mã nguồn, với máy chủ thử cục bộ: MP4, HLS 360p/720p, HLS trả 403 giữa chừng, MP4 18,4 MB chạy chậm, file `.exe` giả video, trang có iframe. Mỗi màn hình kiểm ở cả giao diện sáng và tối.

Bản thử có 3 thay đổi chỉ dùng cho QA, không đưa vào mã nguồn:

- popup nhận `?qaTab=` để trỏ vào tab cần kiểm;
- ghi lại tên file tiện ích xin lưu.

## Đã kiểm, đạt

- Tải MP4: đúng byte.
- Tải HLS 720p: ffprobe ra 1280×720, H.264 + AAC, 40,1 s.
- Link hết hạn: tab Lỗi có nguyên nhân và nhật ký; Tải lại chạy được.
- Tạm dừng / tiếp tục: file trùng MD5; máy chủ nhận 10 request khúc thay vì 15.
- Nút trong iframe.
- Không có lỗi console.

Mỗi lỗi một commit kèm test hồi quy; test đỏ trên code cũ, xanh sau khi sửa. Muốn trả về bản trước khi sửa: `git checkout e9fea11 -- <file>`.
